# Support

Use the right GitHub surface so questions and contributions stay easy to triage.

- Use issues for reproducible bugs and focused feature requests.
- Use pull requests for proposed fixes and improvements.
- Use [security reporting](SECURITY.md) for vulnerabilities or anything that might expose credentials, private data, or sensitive runtime details.

Before opening an issue, search existing issues and pull requests to avoid duplicate reports.

Download macOS ARM64 and Windows x86-64 binaries from [GitHub Releases](https://github.com/stephenlclarke/defender/releases). See the [player guide](docs/PLAYING.md) for extraction, controls, checksums, and unsigned-download prompts. For a runtime problem, include the archive filename or commit, OS version, CPU architecture, GPU, graphics driver, and whether `--mute` changes the result. Rendering uses WGPU; a compatible GPU and working driver are required.
