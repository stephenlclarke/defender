# Pull Request 10

## Summary

Build and package the WGPU game for macOS ARM64 and Windows x86-64. Upload archives and SHA-256 sidecars as workflow artifacts, and publish them on version tags. Native builds run target tests and standalone actor smoke checks; macOS also checks offscreen WGPU rendering.

## Type Of Change

- [x] Maintenance or workflow update
- [x] Documentation update

## Motivation And Context

Players need downloadable native binaries. The runtime already creates and presents a WGPU surface. A real GPU smoke check exposed invalid Rust visibility modifiers inside the embedded WGSL shader. The accompanying renderer fix removes them and adds Naga parsing/validation coverage. See [ISSUE-desktop-releases.md](ISSUE-desktop-releases.md).

## Implementation

Add native build/release jobs with read-only build permissions and a tag-only publishing job. Package only the executable and player/support instructions. Validate archive architecture and checksums. Statically link the Windows MSVC runtime. Document downloads, unsigned binaries, required graphics drivers and local packaging. Expand Markdown lint coverage and allow logical paragraph lines. The accompanying shader fix adds parser validation. The branch includes the current upstream dependency and Clippy updates.

## Testing

Packaging tests pass for both archive formats, executable permission preservation, checksums, wrong/truncated binaries and invalid versions. Workflow lint, documentation lint, Rust formatting and Clippy pass. All 396 Rust tests pass on macOS ARM64. The extracted macOS release package passes actor/attract smoke checks and renders 192 nonblank WGPU steps outside the repository. Native target tests and Windows validation run in GitHub Actions.

## Compatibility And Remaining Risks

Gameplay and key bindings are unchanged. Windows releases target x86-64 only. Binaries are unsigned, and macOS notarization is not configured. Windows hardware graphics/audio playtesting remains separate from hosted build checks. Publishing requires pushing a version tag after merge; this change does not create a version tag.
